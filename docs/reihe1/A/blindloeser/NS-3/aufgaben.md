# Blindlöser NS-3

Antwortform: Gib alle Lösungen an, getrennt durch Semikolon, z. B. „2; −5“. Gibt es keine, schreib „keine Lösung“.

## Aufgabe 1

Bestimme die Nullstellen von f(x) = 2(x + 3)(x − 6).

## Aufgabe 2

Bestimme die Nullstellen von f(x) = 2(x − 1)(x + 4).

## Aufgabe 3

Bestimme die Nullstellen von f(x) = 2(x − 1)(x − 9).

## Aufgabe 4

Bestimme die Nullstellen von f(x) = (x + 6)(x − 3).

## Aufgabe 5

Bestimme die Nullstellen von f(x) = 2(x + 8)(x − 6).

## Aufgabe 6

Bestimme die Nullstellen von f(x) = x(x − 8).

## Aufgabe 7

Bestimme die Nullstellen von f(x) = 2(x − 8)(x − 1).

## Aufgabe 8

Bestimme die Nullstellen von f(x) = (x − 6)(x − 2).

## Aufgabe 9

Bestimme die Nullstellen von f(x) = (x + 7)(x + 3).

## Aufgabe 10

Bestimme die Nullstellen von f(x) = x(x − 2).
