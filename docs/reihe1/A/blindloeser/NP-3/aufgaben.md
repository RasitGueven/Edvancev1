# Blindlöser NP-3

Antwortform: Gib die Zeilennummer und den Buchstaben der Begründung an.

## Aufgabe 1

Noah hat x² − 4x = 0 gelöst. In welcher Zeile steckt der Fehler, und warum?
Zeile 1: x² − 4x = 0
Zeile 2: x² = 4x
Zeile 3: x = 4
Zeile 4: L = {4}
Begründungen:
A: Man darf nicht durch x teilen, x könnte 0 sein. So geht die Lösung x = 0 verloren.
B: Die Zahl hätte mit umgekehrtem Vorzeichen auf die andere Seite gemusst.
C: x² geteilt durch x ergibt nicht x.
