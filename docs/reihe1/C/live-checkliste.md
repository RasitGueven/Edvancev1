# Reihe 1 · C · Live-Checkliste (nach dem Merge, mit einem Testkind vor Ort)

Voraussetzungen: PRs in Merge-Reihenfolge gemergt (siehe `bericht.md`), Bauform-Instanzen von A freigegeben
(sonst zieht die Session nichts, `pool_leer`), Testkind mit Testkonto und laufendem Vertrag, ein Coach, ein Tablet.
Testlauf-Sessions buchen keine Belege und planen nicht neu — für die Punkte mit (B) eine normale Session nehmen.

## Vor der Session (Coach-Sicht `/coach/session/:id/live`)
- [ ] Vorher-Briefing: Karte „Reihe“ kompakt oder nichts, wenn das Kind noch keine Reihe hat.
- [ ] Check-in: Feld „Klassenarbeit am“ vorbelegt mit der Antwort des Kindes; „Datum bestätigen“ legt die Reihe an.
- [ ] Datum in acht Wochen: Karte zeigt „Session 1 von 8“, letzte Session Generalprobe.
- [ ] Datum in sechs Wochen: Warnung „Die Reihe passt nicht in 6 Sessions: … fällt weg“, Extremwerte zuerst.
- [ ] Kind-Detail: „Skill verschieben“ auf einen anderen Termin → dort „vom Coach verschoben“; „Plan bestätigen“ → „Plan bestätigt“.

## Am Tablet
- [ ] Warm-up: 3 Aufgaben, kein Hinweis-Knopf; Session 1 nur Voraussetzungen (Koordinaten, Einsetzen, …).
- [ ] Neuer Skill: erst Erklärung (Video, wenn B freigegeben, sonst Karten), dann Lösungsbeispiel, dann ähnliche Aufgabe.
- [ ] Falsche Antwort: Fehlbild-Satz, danach eine Aufgabe derselben Bauform und Stufe (Zwilling).
- [ ] Richtig in Gold, nie Mastery-Grün.
- [ ] Kurz vor Schluss: Recap ohne Hinweis-Knopf; danach Check-out ohne Termin-Wahl, mit „Zuhause weiterüben“.
- [ ] (B) Nach dem Abschluss: Danach-Ansicht zeigt „Neuer Reihenplan“ mit Änderungen.

## Zweite Session derselben Reihe (B)
- [ ] Warm-up beginnt mit einem Abruf aus Session 1 (Coach-Detail: Grund „Abruf … (fällig)“).
- [ ] Kachel: „Session 2 von 8“.

## Generalprobe (Reihe mit Klassenarbeit am nächsten Tag)
- [ ] Aufgaben ohne Hinweis-Knopf, keine Rückmeldung bis zum Ende.
- [ ] Danach „sicher / noch üben“ je Skill; Tipp auf „noch üben“ startet Übungsaufgaben zu genau diesem Skill.
- [ ] Coach-Detail: Block „Generalprobe“ zeigt „läuft“, nach dem Ergebnis „sicher / noch üben“.

## „Zeig's mir“ (braucht D, siehe `an-D.md`)
- [ ] Coach übernimmt im Check-in → erste Kernaufgabe ist eine Aufgabe dieses Skills ohne Hinweis-Knopf.
- [ ] „Nicht heute“ → normale Kernarbeit.

## Zuhause (D)
- [ ] Eine Home Quest ändert weder den Befund (Themenbaum, Lernpfad) noch den Reihenplan.
