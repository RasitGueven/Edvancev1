# Zweitprüfung gleichung_quadr_faktor · Runde 3 (nur neue Stufe 3 von -01, -03, -04)

Geprüft wurde jeweils die Stufe 3 im Zusammenhang mit Aufgabe, Lösungsweg, Stufe 1/2 und den Fehlbildern.
Der neue Zusatz „trag die kleinere Lösung zuerst ein“ verrät bei keiner der drei Aufgaben, welche Lösung
die kleinere ist, und auch keinen Zahlenwert. Er verrät nur, dass es zwei Lösungen gibt, und das steht
schon im MULTI_PART-Format und im Nullprodukt-Gedanken.

## quadrgl-faktor-03 · 3x² = 12x · **ok**
- Keine neue Teillösung: 3x · (x − 4) = 0 stand schon vorher in der Stufe. Die Reihenfolge-Erinnerung legt 0 bzw. 4 nicht fest.
- Zwei Sätze, Wir-/Du-Form, kein richtig/falsch, 142 Zeichen. Passt zum Lösungsweg (Faktoren null setzen, zwei Gleichungen).
- Zahlen: 3x · (x − 4) = 3x² − 12x ✓.

## quadrgl-faktor-01 · x² − 5x = 0 · **kann**
- Keine Lösung verraten, zwei Sätze, Form passt, Zahlen stimmen (x · (x − 5) = x² − 5x ✓), 182 Zeichen.
- Durch die Kürzung ging etwas verloren: Gegen das Fehlbild vorzeichen_aus_klammer (Antwort −5) wirkte
  „wann die Klammer null wird“ als Denkweg. „Achte bei x − 5 auf das Vorzeichen“ ist nur ein Signalwort und lässt
  sich sogar falsch lesen („da steht minus, also −5“). „Prüfe beide Faktoren“ ist auch schwächer als „gleich null setzen“.
- Vorschlag (165 Zeichen): „Wir klammern x aus: x · (x − 5) = 0. Setze beide Faktoren gleich null, überlege bei x − 5 genau, wann die Klammer null wird, und trag die kleinere Lösung zuerst ein.“

## quadrgl-faktor-04 · x · (2x − 7) = 0 · **ok**
- Keine neue Teillösung: Die Schritte + 7 und : 2 standen schon vorher in der Stufe. Die Erinnerung legt 0 bzw. 3,5 nicht fest.
  Sie passt gut hierher, denn das Kind rechnet zuerst 3,5 aus und würde es sonst leicht zuerst eintragen.
- Zwei Sätze, Wir-/Du-Form, kein richtig/falsch, 162 Zeichen. Zahlen: 2x − 7 = 0 → 2x = 7 → x = 3,5 ✓.
